# Array Manipulation

A simple Java project designed to demonstrate various array manipulation techniques and algorithms.

## 🚀 Features
* **Search Operations:** Linear search and binary search implementations.
* **Sorting Algorithms:** Essential sorting techniques (e.g., Bubble Sort, Selection Sort).
* **Utility Functions:** Element insertion, deletion, reversing an array, and finding minimum/maximum values.
